# 🍔 Food Delivery System

## 📌 Overview
The Food Delivery System is a web application that allows users to browse restaurant menus, place food orders, and manage deliveries through a simple and user-friendly interface. It provides an efficient platform for customers, restaurants, and administrators to manage the complete food ordering process.

---

## ✨ Features

### 👤 User
- User Registration & Login
- Browse Food Menu
- Search Food Items
- Add to Cart
- Place Orders
- View Order History

### 🍽️ Restaurant
- Manage Food Menu
- Update Food Prices
- Accept or Reject Orders
- Track Incoming Orders

### 🛡️ Admin
- Manage Users
- Manage Restaurants
- Manage Food Items
- Monitor Orders
- Generate Reports
